# Physics-Informed Neural Networks for Nonlinear Analysis of Composite Thin-Walled Shells

This repository contains the implementation and numerical examples for the paper **“Physics-informed neural networks for nonlinear analysis of composite thin-walled shells.”**

The work develops a physics-informed neural framework for nonlinear bending and flattening analysis of composite thin-walled shells. Both **strong-form equilibrium residuals** and **weak-form total-potential-energy formulations** are implemented and compared.

Representative examples include:

* Flat composite strips
* C-shaped composite shells
* Half-Omega composite shells
* Shells with different initial curvatures and laminate orientations

The models are trained without pre-generated mechanical response datasets. Finite element simulations are used for validation and comparison.
